## 0. 계약 성격 (고객사 요구 정리)

- **범위:** 해외 마케팅용 **바이럴 광고 소재 제작·편집** (광고 이미지 + 영상) + **광고 기획/컨설팅**
- **인플루언서 영상:** 고객사가 **원본 소재 제공** → 우리가 **재편집·재가공**
- **추가 문의 2건:**
  1. "기획도 가능하면 기획까지 해주면 좋겠다" → **기획을 상품화**해야 함(별도 가치)
  2. "대표님 쪽에서도 (영상) **자체 제작 가능한지**" → **자체 제작 트랙**도 견적에 포함
- **핵심 판단:** 고객사(COSRX)는 글로벌 대형 K-뷰티 브랜드 → **저가 프리랜서 포지션 금지**, "AI 가속 전문 크리에이티브 스튜디오"로 포지셔닝.

## 2. ① 과금 구조 전략 — **하이브리드 3층 구조 (권장)**

순수 정액제도 순수 종량제도 답이 아니다. **셋업(1회) + 리테이너(정액) + 종량(초과·단발)** 3층으로 간다.

```
[1회] 세팅비 ──────────  브랜드킷·톤앤매너·템플릿/디자인시스템·워크플로우 구축
[월]  리테이너(정액) ──  매월 보장 물량 + 기획/컨설팅 포함 (관계·전략의 척추)
[건]  종량 단가표 ─────  리테이너 초과분 · 대형 단발 캠페인 · 자체 영상 제작
```

**왜 이 구조인가**
- **정액(리테이너):** 매월 안정 산출량과 매출 예측 → 팀 상시 가동. **기획/컨설팅을 여기 포함**해 "기획까지 해달라"는 요구를 자연스럽게 상품화.
- **종량:** 물량 변동·대형 캠페인·자체 제작을 유연하게 흡수. 고객사도 "쓴 만큼" 납득.
- **세팅비:** 첫 달 실제 공수(브랜드 리서치·톤앤매너·재사용 템플릿·디자인시스템 구축)가 크다 → **"브랜드 크리에이티브 킷 구축비"**로 명분 확보. 이후 모든 산출물의 속도·일관성이 여기서 나옴.

## 3. ② 견적 금액 산출 방식 (Calculation Method)

**원가기반(공수×단가) + 시장앵커 + 사용권 승수**로 SKU 단가를 정하고, 리테이너는 SKU 묶음에 번들 할인을 적용한다.

### 3-A. 표준 산출물(SKU) 단가표 — 종량 기준
| SKU | 정의 | 권장 단가(₩) | 시장앵커 |
|---|---|---|---|
| 정적 광고 이미지 1컷 | 카피+합성 포함, 채널 규격 1종 | **80,000~150,000** | 국내 5만~, 프리미엄 반영 |
| 숏폼 영상 편집(소스 제공) | ~40초, 자막·모션·색보정 | **150,000~350,000** | 국내 기본 5~15만+난이도 |
| UGC 인플루언서 영상 재편집 | 원본 재구성·훅·자막·현지화 | **200,000~400,000** | UGC 프로 $500~1,200 하회 |
| 자체 영상 제작(기획+제작 1편) | 컨셉→촬영/AI생성→편집 | **500,000~1,500,000** | 글로벌 $5K~ 대폭 하회(AI가속) |
| 광고 기획/컨셉(캠페인 1건) | 컨셉·메시지·스토리보드·소재맵 | **500,000~2,000,000** | 컨설팅 가치 |

### 3-B. 사용권(Usage Rights) 승수 — 해외 유료광고
- 한정(1채널·3개월) = **base(×1.0)**
- 확장(전 유료채널·6~12개월) = **×1.3 (+30%)**
- 영구/전채널 = **×1.5~2.0 (+50~100%)**

### 3-C. 리테이너 산식
```
월 리테이너 = (월 보장 SKU 합계 정가) × 번들할인(0.7~0.8) + 기획/컨설팅 정액
```
→ 볼륨을 묶어 **정가 대비 20~30% 할인**을 제공하되, 상시 가동으로 총액을 확보.

### 3-D. AI 가속 마진 원칙
- 변형(variant) 한계비용≈0 → **동일 리테이너로 경쟁사보다 2~3배 물량** 제공 가능 = 우리의 해자.
- 단, **대외 단가는 "산출물 가치" 기준**으로 책정(원가 노출 금지). 효율은 마진으로 귀속.

## 4. ③ 컨설팅·대행 모델 (Engagement Model)

### 4-A. 3단계 관여 모델 — 고객사가 고르게
| 트랙 | 내용 | 과금 |
|---|---|---|
| **A. 기획·컨설팅 only** | 컨셉·메시지·소재 전략·레퍼런스 | 프로젝트/리테이너 |
| **B. 제작 대행** | 이미지·영상 제작/편집(기획은 고객사) | 종량 or 리테이너 |
| **C. 풀 파트너(권장)** | 기획+제작+편집+운영 일괄 | **세팅비 + 리테이너 + 종량** |

### 4-B. 영상 2-트랙 (고객사 문의 직접 응답)
- **트랙 1 — 재편집:** 고객사 인플루언서 원본 → 훅·자막·현지화·리사이즈로 **광고용 재가공** (강점·저비용)
- **트랙 2 — 자체 제작:** 대표님 팀이 **기획부터 제작까지** (AI 영상팀 + 실사 촬영 옵션). "자체 제작 가능?"에 **가능**으로 답하되 **별도 SKU**로 견적.

### 4-C. 표준 워크플로우 (품질 게이트 내장 — 기존 팀 구조 활용)
```
Brief → 기획(컨셉·스토리보드) → 제작(AI+휴먼) → QA(이중 게이트) → 납품 → 성과 피드백
```
→ 이미 구축한 **AI 영상/디자인 팀(오케스트레이터+전문에이전트+QA)**이 그대로 생산 엔진.

## 5. 권장 제안안 (COSRX 제시용 초안 — 조정 전제)

> COSRX = 대형 계열 브랜드(§1-D)이므로 하한을 국내 프리랜서가 아닌 **전문 스튜디오 티어**에 둔다. 다제품군·북미 볼륨을 근거로 **Standard~Enterprise**가 현실적 착지점.

- **세팅비(1회):** ₩3,000,000~5,000,000 — 브랜드 크리에이티브 킷(톤앤매너·템플릿·디자인시스템·워크플로우) 구축. *다제품군이면 라인별 킷 추가 시 가산.*
- **리테이너 티어(월):**
  | 티어 | 월 정액(₩) | 월 보장 물량(기획 포함) | 적합 대상 |
  |---|---|---|---|
  | Lite | 3,000,000 | 이미지 15컷 + 숏폼 5편 | 단일 라인 테스트 |
  | Standard | 5,500,000 | 이미지 25컷 + 숏폼 10편 + UGC 재편집 5편 | 1~2개 라인 |
  | **Pro(권장)** | 8,000,000~10,000,000 | 이미지 40컷 + 숏폼 15편 + UGC 8편 + 운영 | 다제품군·북미 상시 |
  | Enterprise | 12,000,000+ | 커스텀(다라인 병렬·전담 인력·주간 스프린트) | 그룹 단위 프로그램 |
- **종량 단가표:** §3-A 적용 · **사용권 승수:** §3-B 적용(해외 유료광고 전제)
- **다제품군 확장:** 라인 추가 시 **라인별 애드온**(예: +₩1,500,000/월/라인) 또는 상위 티어 이전.
- **계약 조건:** 최소 3개월, 월 물량 이월 1개월, 중도해지 잔여 50%, 수정 라운드 2회/건, 사용권·독점은 별도 합의.

> ⚠️ 위 금액은 **시장앵커 기반 권장 레인지**입니다. COSRX의 실제 물량·기간·사용권·독점 여부로 최종 캘리브레이션이 필요합니다.

## 6. 다음 단계 & 확인 필요

1. **포지션 확정** — 우리 최종 마진 목표(예: 리테이너 대비 원가율 40~50%?) → 티어 금액 확정.
2. **물량 가정** — COSRX 월 예상 소재 수량(이미지/영상/UGC)? → 티어/종량 비중 결정.
3. **사용권·독점** — 해외 유료광고 채널·기간·경쟁사 독점 여부? → 승수 확정.
4. **자체 촬영 여부** — 실사 촬영까지 제공? → 자체제작 SKU 상·하한.
5. 확정되면 → **정식 견적서(제안서)** 문서로 렌더(디자인팀 산출).
