# [리서치 브리프] 생성 엔진 선정 — 이미지=GPT Image 확정 / 영상=Veo3 vs Seedance vs Higgsfield

> 인계: 사이드챗 → AI 영상제작팀 (리서치 담당 수행)
> 목적: COSRX 아마존 바이럴 소재 대량 생산을 위한 **생성 엔진 스택 확정 + 실측 수치 확보**
> 상태: **미실행(팀에서 조사 필요)** · 작성 2026-08-15

---

## 0. 배경 (왜 이 결정이 중요한가)
사이드챗에서 나온 우리 격차 3가지 — 이 엔진 결정이 이걸 메운다:
- **이미지 생성 롤이 파이프라인에 안 물림** — imagemaker(OpenAI/Grok/Gemini) 아직 미구축. 기존 COSRX 100개는 사실상 **수작업(Claude Design)**.
- **변형 공장(variant factory) 부재** — "컨셉1 → 변형20"을 자동으로 뽑는 워크플로우 없음.
- **측정 수치 부재** — "몇 개를 몇 시간에 얼마에"라는 정량 증거가 없어 아직 정성적 주장.
→ 포지셔닝("AI 가속 퍼포먼스 스튜디오")을 **데이터로 증명**하려면 엔진을 정하고 벤치 수치를 떠야 함.

## 1. 확정 사항
- **이미지 생성 = GPT Image 생성 API (확정)**  ← 재론 불필요, 파이프라인 연결 대상
- 영상 생성 = **미확정** → 아래 3안 비교로 결정

## 2. 결정 대상 — 영상 엔진 3안
| 안 | 형태 | 메모 |
|---|---|---|
| A. **Google Veo 3** | 직접 API(Gemini) | 최초 검토안. 팀 파이프라인이 이미 Gemini 계열 사용 |
| B. **Seedance 직접 연결** | 직접 API | "요즘 대세" — 직접 연동 검토 |
| C. **Higgsfield Studio** | 스튜디오/래퍼(Seedance 등 포함 가능) | 사용성↑ 대신 비용·API화 제약 확인 필요 |

## 3. 평가 축 (반드시 이 항목으로 비교표 작성)
1. **비용** — 초당/영상당 단가, 요금제, 상업적 사용권, 크레딧 구조
2. **생성 품질** — 해상도·프레임·리얼리즘, 뷰티 제품 표현력
3. **스토리라인** — 멀티샷/시퀀스 일관성, 프롬프트 준수
4. **카메라 효과** — 무빙/줌/앵글 컨트롤 정밀도
5. **캐릭터 동작** — 인물 모션 자연스러움, 손·얼굴 안정성 (뷰티 UGC 핵심)
6. **품질/일관성** — 배치 간 캐릭터·톤 일관성, 재현성
7. **사용성/연결성** — **API 유무**(자동화 가능?), 워크플로우 통합, ffmpeg 합성 연계, 러닝커브

## 4. 산출물 (팀이 낼 것)
- **3안 × 7축 비교표** (실측 근거·출처 포함, 가격은 조회 시점 명기)
- **권장안 1개** + 이유 (COSRX 뷰티 UGC/아마존 소재 기준)
- **연결 방식 결론** — 직접 API vs Higgsfield 스튜디오 (자동화·변형공장 관점)
- (가능 시) **벤치 수치** — "동일 컨셉 영상 N편 / X시간 / ₩Y" 초안

## 5. 특별 고려 (COSRX 맥락)
- 인플루언서 원본 **재편집** 트랙과 **자체 생성** 트랙 둘 다 필요 → 엔진은 자체 생성용.
- 아마존/릴스 세로 1080×1920, 훅 3초, 컴플라이언스(과장·비포애프터) 세이프.
- 이미지(GPT Image)로 정지컷 + 영상엔진으로 모션 → ffmpeg 합성 파이프라인 전제.

## 6. 다음 (엔진 확정 후)
→ imagemaker(GPT Image) + 선정 영상엔진을 파이프라인에 연결 → **변형 공장** 워크플로우 구축 → COSRX 파일럿으로 **벤치 수치** 확보 → 포지셔닝의 증거로.
